# Skills 安装管理与 Agent 调用闭环

日期：2026-10-09。来源：用户明确批准的实施计划。关联任务：CORE-SKILLS-102、APP-SETTINGS-103。前置实现见 `2026-10-08-agent-tool-settings.zh-CN.md`。

## 契约

- 安装默认 Core 共享作用域，可选项目；共享安装不要求先创建项目。共享资源 ID 更新时保持，内容版本不可变。项目资源 ID 从租户、工作区、项目及包路径确定。
- 市场两阶段预览/应用保留完整包文件及摘要，审批参数使用 Core 冻结内容。预览不写入。JSON 索引保留；GitHub 来源必须是公开 HTTPS 的 `tree/<40字符提交>/<可选目录>`。禁止凭据、未固定分支、截断 Git 树、链接、子模块、包外路径和内容对象哈希不符。
- 包管理读取完整清单；未提供附件时保留已有附件，替换附件集合必须明确 `replace_files=true`。目录导入读取 frontmatter 名称。文件预算为最多 256 项、16 MiB；SKILL.md 最多 256 KiB。
- 项目写入和删除使用受治理动作，冻结逐文件哈希、快照和审批。二进制附件经过与文本相同的路径、哈希和审批边界。卸载默认停用；删除拒绝陈旧 revision、哈希及用户修改。
- 包详情/文件预览只接受资源 ID 与相对路径，Core 校验真实根和链接。安装状态与实际可读可发现状态分别投影。
- 准入冻结共享和项目包完整版本；恢复、派生及旧运行使用原包。项目编辑保持 live 项目来源，准入副本位于 Core 内容存储。
- 读取提示匹配 Agent 实际可用工具：read_file、shell、command_run；均不可用时不发布 Skills 索引。绑定遵循继承、空列表和精确 ID。绑定不撤销普通项目读取权限。
- command_run 额外写授权不得与技能只读根、父目录或链接目标重叠。
- Desktop 显示来源、版本/提交、文件、正文、资源预览、启停和诊断；审批轮询包含对象过期防护。Skill 市场详情不渲染 MCP 运行区。MCP 资源配置、连接测试与运行清单分别展示。
