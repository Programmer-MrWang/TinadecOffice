## ⚠️ git 仓库损坏与修复
- 现象：.git/objects/pack 的 .pack 文件全部丢失（仅剩 .idx）、refs/heads/main 丢失、reflog 为空、所有对象不可读 → "bad object HEAD"。
- 诱因疑与沙箱化 git stash 中断有关；幸运的是远程 main (a3af869) 与本地 HEAD 一致，无未推送提交。
- 修复流程（可复用）：删损坏的 packed-refs/refs → `git fetch origin` 重建对象库 → `git update-ref refs/heads/main refs/remotes/origin/main` → 按远程重建其余本地分支 → 删陈旧 multi-pack-index 与 commit-graphs → `rm .git/index && git reset` 重建索引 → `git fsck --connectivity-only` 零错误。工作区全部改动完好保留。
